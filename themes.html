论点

AI进入生产环境后，身份、权限、审计、日志、数据边界、提示词安全、模型路由和网络可观测性会从合规功能升级为基础设施预算。

Agent 身份是这一轮新长出来的控制面，按 agent 要过的门分三组：企业门（Okta、SailPoint、Palo Alto 的 Idira、CrowdStrike、微软）、开放网络门（Cloudflare 的 Web Bot Auth，Akamai、GoDaddy）、机器门（Zscaler、Netskope；密钥在身份厂商手里）。

证据（财报与产业数据）

IBM已确认快速变化的网络安全环境影响客户交易签约；围绕数据归属、缓存位置与提示词安全的讨论说明，AI部署越深入，安全与权限越靠近采购核心。

网络与边缘侧同步验证：NET收入+36%、10万美元以上大客户+27%、净留存率120%；AKAM安全收入+10%至6.04亿美元，同时云基础设施收入+39%。

OKTA提供目前最直接的会计层交叉验证：FY27 Q1收入仅+11%，但RPO +16%、cRPO +12%都快于当期收入确认——长约在累积。CEO把AI agent定义为组织内部正在出现的新员工，产生必须与人类用户一同被治理的身份。裁决点是cRPO：如果agentic identity是真需求，它应该先于收入加速。

2026-08-26 裁决：该预测兑现。OKTA cRPO同比+14%、较上季+12%加速，且快于收入约+11%，公司称是自FY25 Q4以来最大的cRPO超预期——领先指标确实先动了。但只算部分验证：Q3的cRPO指引回落到+11%至+12%，加速尚未证明连续。

凭什么是未来的主线

Muse 给每个用户配一台带浏览器的专属虚拟机，agent 的负载主要吃 CPU 和内存：每 GW 数据中心的 CPU 核从 3000 万到 1.2 亿（Arm 估算），服务器 CPU 3 月以来最多涨价 20%、英特尔交期最长 6 个月。CPU 这一层 9/21 已站在 9EMA 上方 14–20%。

冲突在门口：Amazon 9/20 封杀 Muse，理由是 agent 隐藏身份、留存凭证。解决方案是 Web Bot Auth 签名认证加 agentic token 受限卡号——Visa、Mastercard 的 agent 支付都用它认证。身份一侧（NET、OKTA、CRWD）已贴 52 周高，支付一侧（V、MA）21 日 ±1%。

升级信号

主题组 40% 以上个股收在 52 周高点 5% 以内，这是主线的定义本身。2026-11-20 口径：本线 11 只 0/11，最近的 MA −8.3%、V −9.0%；moomoo AI Agent 组 0%，最后一次过 40% 是 10/13。

Meta 披露 Muse 付费用户规模。10/21 披露账户超过 1000 万、日活约四分之一，开发者申请 1500 份，付费仍未披露。第二家平台表态这一半已兑现：eBay 11/12 限制含 Muse 在内的第三方 agent。

Visa 或 Mastercard 第一次给出 agent 交易的量级。10 月下旬财报：Visa 称近 50 家 AI 合作方已上线，没给交易量；Mastercard 没给数字。

作废条件

Meta Connect（9/23）及之后没有付费转化或开发者接入数据，Muse 停在下载榜单层面。

英特尔、AMD 三季报显示服务器 CPU 交期缩短、提价停止——CPU 需求线被供给追上。

Amazon 与 Meta 和解且再无第二家平台封杀，门禁冲突降温，身份认证层失去紧迫性。

凭什么是未来的主线

订单和利润还在加速：应用材料把 2026 年设备增速上调到 40% 以上，并给出 2027 年行业 +30% 以上；泛林单季收入 +54%；ASML 年内第三次上调全年指引。但增量换成了存储，应用材料设备收入里 DRAM 从 26% 升到 33%，代工逻辑环比约 −2%。2027 年能走多快，卡在洁净室和零部件。

股价按存储周期定价，不按自己的订单：7 月以来美股四家对美光相关 0.78~0.86，对英伟达只有 0.54~0.56。前道和存储 6 月底同一周见顶，爱德万跟 GPU 在 10 月初创新高。出口管制的另一侧是中国本土设备，年初至今 +26%~+98%。

七家 40% 以上收在 52 周高点 5% 以内，这是主线的定义本身。2026-11-20：0/7，最近的 ASM 国际 −41.5%。

下一轮财报（泛林、科磊 1 月下旬，应用材料 2 月中）反应日跑赢 SMH、到第 5 天仍为正；这一季 5 家到第 5 天全部为负。

美光 12 月财报后存储先转强；应用材料代工和逻辑设备收入恢复环比增长（四季度约 −2%）。

作废条件

存储厂或云厂商下调 2027 年资本开支。11/05 数据中心停建担忧当天，SMH −11.2%。

应用材料 2 月把 2027 年行业 +30% 以上的判断下修，或台积电 2027 年资本开支低于 2026 年。

How it works

怎么改

改 data/themes.json，然后跑 python scripts/build_themes.py。 脚本会先跑闸门（专题文件不存在、主线没挂专题、rank 与强度不一致、超过 7 天没复盘、 单段超 220 字、有专题没登记 —— 任何一条都直接失败）， 通过后重生成本页并把 NARRATIVES 写回财报助手的 index.html。 最后在财报助手仓库跑 node check-narratives.js 复核。
