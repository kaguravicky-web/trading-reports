AI Agent 产业链深度：CPU 回归 × 门禁之争 × 各层定价

Agent 把算力从 GPU 往 CPU 和内存挪，这一层的股价已经先跑到了最贵的位置；真正的冲突在门口——谁有权让 agent 进来，而管门的支付那一层价格还没动。

9 月 8 日 Meta 发布个人 agent Muse，十天冲到美区 App Store 第一；9 月 20 日 Amazon 把它挡在商城门外； 9 月 21 日 Meta 单日 +11.43%、CPU 三家 +10% 到 +17%。 本篇从 Muse 的产品结构出发，按算力 → 门禁 → 支付 → 存储拆开这条链， 再用 2026-09-21 收盘给六层标的各算一遍位置。

读这篇需要的词

只收这一篇用到的。

Agent vs 聊天机器人
聊天机器人回答问题；agent 替你做事——打开网页、填表、下单、发邮件。 差别不在模型，在于它要长时间占着一台电脑去操作别人的网站。
Secure VM 专属虚拟机
Muse 给每个用户开一台独立的云端电脑，里面有自己的浏览器。 这台电脑跑的是网页、表单、登录流程，主要吃 CPU 和内存，不是 GPU。
CPU:GPU 比例
数据中心里每块 GPU 配几颗 CPU。训练时代 CPU 只负责喂数据，比例很低； agent 时代大量工作是「开浏览器、调接口、等网页」，比例往 1:1 走。
Web Bot Auth 机器人身份签名
让 agent 在访问网站时用加密签名证明「我是谁、代表谁」。 网站据此决定放不放行、收不收费。Cloudflare 主导，Visa 和 Mastercard 的 agent 支付协议都用它做认证。
Agentic Token agent 专用卡号
发给 agent 的受限支付凭证：可设限额、限商户、限时间，持卡人随时一键吊销。 agent 拿不到你的真实卡号。
距 9EMA / 距 50MA（ATR）
价格偏离短期和中期均线多远。距 9EMA 用百分比，距 50MA 用 ATR 倍数—— 后者把波动大小不同的票放到同一把尺上。

Answer first

四条结论

  1. Muse 真正的新东西不是模型，是「每人一台电脑」。 它给每个用户配一台带浏览器的专属虚拟机，替你登录、填表、下单。 这种负载主要吃 CPU 和内存——Arm 的估算是 agent 时代每 GW 数据中心需要的 CPU 核从 3000 万涨到 1.2 亿， CPU:GPU 比例从很低走向 1:1 到 1:2。服务器 CPU 价格 3 月以来最多涨了 20%，英特尔部分订单交期拉到 6 个月。
  2. CPU 这一层已经在价格里，而且是最贵的位置。 9/21 收盘 AMD、INTC、ARM 分别站在 9EMA 上方 +14.4%、+14.7%、+19.7%， 折合约 3 到 4 个 ADR；RSI 74 到 78。AMD 离 52 周高点只差 0.2%，市值首次破万亿。 逻辑是对的，价格已经先跑到了逻辑前面。
  3. 冲突发生在门口，而门禁层只有一半被定价。 Amazon 9/20 封杀 Muse，理由是 agent 访问时隐藏身份。解决这个问题的就是 Web Bot Auth—— Visa 和 Mastercard 的 agent 支付协议都拿它做认证，Cloudflare、Akamai、AWS 已在生产环境验签。 身份安全那一侧（NET、OKTA、CRWD）已经贴着 52 周高点；支付那一侧（V、MA）21 日几乎没动，RSI 只有 39 和 32。
  4. 存储是这条链里叙事和价格打架最厉害的一层。 agent 的虚拟机要内存、要 SSD，道理上是需求端的增量。 但 9/21 半导体全线大涨那天，SNDK 反而 −1.41%； 当晚宏碁 CEO 说 2027 年存储价格会下跌，长鑫开始量产新平台。这一层的决定变量是供给，不是 agent。
The product

Muse 到底新在哪

过去两年的 AI 应用基本都是「你问它答」。Muse 是第一个把「替你操作别人的网站」做成大众消费品、而且真有人用的产品。

日期事件这件事说明了什么
9/8Muse 发布：网页、iOS、Android、WhatsApp 同步上线，仅限美国。免费起步，付费档 $20 / $100 每月定价按用量收费——用得越多越贵，因为每个任务都在消耗一台虚拟机的时间
9/8架构：每个用户一台 Muse Secure VM，带独立浏览器；对话和虚拟机数据不进 Meta 广告系统这是算力结构的变化：一个活跃用户 ≈ 一台常开的云端电脑
9/18美区 App Store 总榜第一，上线 10 天约 73 万次下载，同类里超过 ChatGPT 和 Claude消费者愿意把邮箱、日历、支付交给 agent——这是此前最大的未知数
9/20Amazon 在结账页对 Muse 弹窗拦截：「未经授权的 AI agent 访问违反使用条款」第一次大平台对大型 agent 的正面封杀，理由是隐藏身份、留存用户凭证
9/21META +11.43%（741.25），2025 年 7 月以来最大单日涨幅；call 成交约 180 万张，2022 年 10 月以来最多富国银行把目标价从 $640 上调到 $796，理由是重度用户会被迫付费
9/23–24Meta Connect；主题演讲 9/23 16:00 PT（SGT 9/24 07:00），开发者专场讲 Muse 的构建路径下一个硬信息点：付费转化、开发者接入、合作商户

73 万次下载放在 Meta 的用户盘子里很小，但方向比规模重要。 它回答的是「消费者肯不肯让 AI 拿着自己的账号去操作」——答案是肯。 一旦这一点成立，后面每一层的需求都是按活跃 agent 数 × 每个 agent 占用的算力时长来算的，而不是按聊天次数。

Compute

算力：CPU 回来了

训练模型是 GPU 的活；让 agent 开浏览器、等网页、点按钮、调接口，是 CPU 的活。这一层的变化在 Muse 之前就已经在供应链里出现。

这是一条供给已经跟不上的需求线，涨价和交期拉长是证据。 但也要看到它的另一面：英伟达和 Arm 在 3 月就下场做 CPU 了——高毛利、交期紧的市场一定会引来新产能， 这和存储那一篇讲的是同一个机制，只是时间点更早。

CPU 三家不是同一个赌注。 AMD 是份额和性能都在上升的那一家，价格也最先到位（离 52 周高 0.2%）； 英特尔是产能最多、交期最长的那一家，涨价弹性最大，但离 52 周高还有 14.5%； ARM 收的是授权费，吃的是「核数」而不是「颗数」，离 52 周高还有 28.7%，是三家里弹性最大、也最依赖叙事的一家。

The gate

门禁：谁让 agent 进门

Agent 的价值在于替你操作别人的网站；而网站有权不让它进。Amazon 和 Meta 的冲突不是个案，是这条产业链的核心矛盾。

这一层现在发生了什么谁在收费站上
平台拦截Amazon 9/20 封 Muse，此前已对 Perplexity 的购物机器人拿到临时禁令。理由：agent 不表明身份、会留存用户凭证大平台自己。Amazon 有自己的购物 agent，封别人等于护城河
身份认证Web Bot Auth：agent 用加密签名自证身份。Cloudflare、AWS WAF、Akamai、HUMAN、Vercel 已在生产环境验签；IETF 工作组成立但还没有采纳的标准文档NET、AKAM（网络边缘）；OKTA（Agent SSO，把 agent 当一等身份管理）
默认规则Cloudflare 7 月把「屏蔽 AI 机器人」拆成搜索 / agent / 训练三类；9/15 起新接入域名在带广告页面默认屏蔽 agent。AI 机器人请求已超每周 100 亿次网站主开始有「放行 / 收费 / 拒绝」的开关
支付Visa Intelligent Commerce、Mastercard Agent Pay 已上线，用 agentic token 发受限卡号，认证层用的就是 Web Bot Auth；另一条轨道是 Coinbase 的 x402 稳定币协议V、MA（卡组织）；COIN（x402）
规模估算麦肯锡：到 2030 年美国由 agent 完成的交易约 1 万亿美元——

Amazon 给出的封杀理由，恰好就是这套基础设施要解决的问题。 「agent 隐藏身份」→ 需要签名认证；「agent 留存用户凭证」→ 需要 agentic token 替代真实卡号。 门禁之争越激烈，身份和支付这两层的必要性越强——不管最后是 Meta 赢还是 Amazon 赢， agent 都得先带着可验证的身份和受限的支付凭证才能进门。

两侧的定价完全不同。身份安全那一侧已经涨过：NET、OKTA、CRWD 都在 52 周高点 1% 以内，21 日涨了 26% 到 43%。 支付那一侧没动：V 21 日 +1.15%、MA −1.08%，RSI 39 和 32，都在 50MA 附近。 我们没有证据说明支付一侧「应该」涨——agent 交易目前只有数百笔受控测试，在卡组织的收入里可以忽略不计。 这里能说的只是：这一层的故事已经发生，价格还没有表达它。

被挤压的一侧：靠广告和页面浏览赚钱的网站。agent 不看广告，Cloudflare 默认屏蔽的恰好就是「带广告的页面」。 同时惠普给出 2027 年 PC 出货下降中个位数的假设——如果活儿都在云端虚拟机里干，终端设备的换机理由会更少。这一条目前只是推演。

Memory

存储：叙事和价格在打架

每台 agent 虚拟机都要内存和 SSD，逻辑上存储是受益方，而且需求会跟着活跃 agent 数线性增长。 但 9/21 这一天把矛盾摆得很清楚：SMH +4.02%、SOXX +4.93%，MU 只有 +2.77%，SNDK −1.41%。 当晚宏碁 CEO 说「供应短缺问题已经消失」、2027 年存储价格会下跌，原因是长鑫开始量产新平台。

这和 9/20 存储专题的结论是同一件事：这一层股价的决定变量是供给和资本开支，不是需求。 agent 能拉高需求的斜率，但压不住新产能。在这条链上，存储不是「agent 标的」，是「周期标的」。
