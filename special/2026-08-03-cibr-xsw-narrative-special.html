网络安全深度：Agent 身份认证 × 七笔并购 × 收费与定价

今年安全和软件走成了两个行业。Agent 身份是这一轮新长出来的控制面：钱先以并购进来，方案已经上线，但还没有一家按 agent 数收费——价格走在收入前面的是 Okta，收入走在价格前面的是 SailPoint。

4 月 7 日 Anthropic 发布 Claude Mythos，只开放给 40 多家公司做防御——因为它能批量发现并利用软件漏洞。 之后的第一个完整季度，多家安全公司的订阅指标加速；同一时间，企业里的 agent 用量在快速增长，每一个都要一张能验证、能收回的身份。 本篇先看安全为什么和软件分家、预算加速到了什么程度，再列出围绕 agent 身份的七笔并购， 按 agent 要过的三道门点名做身份认证的公司，最后看钱怎么收、用 2026-09-21 收盘看价格走到了哪一步。

读这篇需要的词

只收这一篇用到的。

非人类身份 NHI
API 密钥、服务账号、OAuth 令牌、证书——机器用来登录系统的凭证。 Agent 是其中最新、也最难管的一种：它会自己决定下一步做什么。
控制面
决定「谁能对什么做什么」的那一层。网络时代是防火墙，云时代是身份。
SSO / Cross App Access XAA
SSO＝员工登录一次、进所有应用。Cross App Access 是 Okta 提出的扩展： agent 凭员工的登录去连别的应用，不用每个应用再点一次授权，IT 可以一处集中收回。
MCP
Anthropic 提出的「agent 连工具」协议。agent 每连一个工具（Slack、Notion、数据库）就是一次授权。
特权访问与密钥管理 PAM
管最高权限的账号和机器用的密钥，CyberArk 的老本行。 零常驻权限＝平时没有权限，要用时临时发、用完即收。
Web Bot Auth 机器人身份签名
agent 访问网站时用加密签名证明「我是谁、代表谁」，网站据此放行、收费或拒绝。
ARR / 净新增 ARR / cRPO
年化订阅收入 / 本季新增的那一块 / 未来 12 个月要确认的合同额。 安全行业先看净新增 ARR 和 cRPO，它们比收入先动。

Answer first

六条结论

  1. 安全和软件今年分成了两个行业，分家发生在上半年。 CIBR 年内 +44.7%、IGV +1.4%。两者 4 月 10 日同一天见底，软件的跌幅是安全的两倍，之后反弹也慢； 7 月以来反而是软件略快——「安全强于软件」这笔相对交易，下半年没有再拉开。
  2. Agent 身份是这一轮新长出来的控制面，钱先以并购的形式进来。 2025 年 10 月以来 7 笔：Palo Alto 买 CyberArk、CrowdStrike 买 SGNL、Okta 买 Permiso、SailPoint 买 Entro、思科买 Astrix、ServiceNow 买 Veza、Twilio 买 Stytch。 SGNL、Astrix、Entro、Permiso 这四家做非人类身份的创业公司，8 个月内都被上市公司买走，这一层的主角变成了大平台。
  3. 三道门，三组公司。 企业门（员工的 agent 进公司自己的系统）最挤：Okta、SailPoint、Palo Alto 的 Idira、CrowdStrike、微软、ServiceNow、思科； 开放网络门（agent 去别人的网站下单）由 Cloudflare 定规矩，Akamai、GoDaddy 同在这一层； 机器门（agent 拿密钥调接口、连 MCP 工具）有 Zscaler、Netskope。 其中两道门已经有在生产环境里跑的方案：企业门是 Okta 的 Cross App Access，开放网络门是 Web Bot Auth。
  4. 收入还没跟上故事：没有一家按 agent 数收费。 财报里看得见的是捆绑溢价和身份线跑赢公司整体，不是「每个 agent 一份钱」；微软的 agent 连许可都不用单独买。
  5. 这一层的价格和收入是错位的。 OKTA 收入增速 +11%，是下面财报表 9 家里最慢的；股价自 4/10 低点 +204%、贴着 52 周高。 SailPoint 给出了这一层最硬的 AI 收入数字，股价离 52 周高还有 15.3%、年内几乎没涨。 这里的定价是按「谁被看成 agent 身份的代表」，不是按「谁的 agent 收入已经最多」。
  6. 放到整个行业看，AI 推得最远的是「卖的东西跟着 AI 用量涨」的公司。 防火墙（FTNT）、软件包仓库（FROG）、端点上的 agent（CRWD、S）、agent 的权限（SAIL）都随用量增长，财报里已经有数字； AI 压得最重的是按人力收费的——外包安全运营的 RPD、政府 IT 外包的 SAIC。

Why identity

Agent 为什么把身份推成控制面

安全行业过去十年的控制面，已经从网络边界挪到了身份。Agent 把这件事再推一步：它是带着员工权限、自己做决定的非人类身份。

维度员工Agent
数量跟着招聘走几周可以翻几十倍：Okta 的一家客户起初发现 50 个 Claude agent，几周后是 1,500 个
在哪HR 系统和目录里都有记录散在各个 SaaS 和员工电脑上：CrowdStrike 看到端点上的 Claude 使用量增长超过 400%、自建 agent 超过 100%
登录一天几次，人在场连续、自动，没人盯着
权限按岗位给，离职收回按任务临时要；现实中常被当成普通服务账号，共用凭证、没有专门的权限和问责
出事追谁员工本人要追到「谁授权了它」——委托链

NIST 2 月 5 日的概念文件把缺口归成三件事： 识别（分清人和 agent、登记它能做什么）、授权（用 OAuth 等标准给权限、随时收回）、委托（把 agent 和授权它的人绑在一起）。 后面每一家公司卖的东西，都落在这三件事的一件或几件上。

企业门最挤，因为 agent 首先是员工的延伸——谁管员工的身份，谁就先有资格管员工的 agent，所以 Okta、微软、SailPoint 天然在这里，平台型公司则靠并购挤进来。 开放网络门的主角，都是本来就站在流量入口的公司。 机器门被两类公司从两头夹住：身份厂商管钥匙，网络厂商管流量。

口径与来源

价格：全部为长桥前复权日线，口径日 2026-09-21 收盘，从日线序列中定位该日那一根计算。 9EMA 为 9 日指数均线；52 周高为近 252 个交易日的最高价。「财报后首日」＝财报发布后第一个交易日的收盘对前一日收盘（盘后发布取次日，盘前发布取当日）；「之后至 9/21」从那一天的收盘算起。

成分：CIBR 的成分与权重取自本地持仓基线，不是 9/21 当日权重；美股成分 38 只、覆盖约 96% 权重，中位数和加权涨幅按这份清单计算。

边界： ① 本篇只讨论 agent 身份这条需求线，不对任何标的给出入场建议； ② PANW 的 NGS ARR 增速含 CyberArk 并表，不是内生增长； ③ 微软、ServiceNow、思科、Twilio、GoDaddy 的身份业务收入没有单独披露、相对公司整体很小，表中股价由主业决定，不归因于身份业务； ④ SailPoint 的「AI 相关产品 ARR」是公司口径，没有拆出其中多少来自 agent 身份； ⑤ 4 月 10 日的年内低点只是价格事实，本篇没有找到那两天下跌的单一原因，不归因于 Mythos； ⑥ 行业地图的「管什么」按各公司自己的业务描述归类，22 家＝网安观察名单；AI 档位是本篇的判断，依据列在表里，不是公司口径。
