  1. Flip / Call Wall / Put Wall 用 moomoo 持仓量自算：≤180 天全链，call 记正、put 记负， 在假想价位按 Black-Scholes 重算 Gamma，求总额由负转正的价格。 本期 AMZN / SPY / QQQ / HOOD 四只的翻转点都在默认扫描区间（−7%～+4%）之外，自动放宽到 ±15% 才找到； 只有 COIN 在默认区间内。
  2. Max Pain 两种算法都列：全链，以及只算现价上下 20 档（Barchart 的默认口径）。 本期 SPY（765 / 751）和 QQQ（710 / 668）差很远，但不是底部平，是窗口截断： 一天跌 4%～6% 之后，以现价为中心的 41 档只覆盖到 753 / 669， 而全链的赔付曲线在 763–766 / 706–712 见底、两边陡升 —— ±20档的结果落在窗口边上，以全链为准。 COIN 的 142 / 141（只差 0.4%）才是真正的底部平。
  3. 11/06 Gamma 峰 = 当天到期这一档里 Gamma×持仓量最大的行权价，call 和 put 分开取。
  4. 预期波幅 = 11/05 收盘时 11/06 平值跨式（call + put）的价格，按收盘价在相邻两档之间插值。
  5. 闸门（进攻线 / 防守线）：20MA + 1×ATR14 / 20MA − 1×ATR14，ATR 用 Wilder(14)， 口径日 2026-11-05 收盘。定义与判定直接取自日报那一套 （report_helpers.gate_rows 与 cross_check_alignment），这里不另立一套。 11/06 的日报取数还没跑，这三行是用同一组函数现算的； 算之前先拿 11/04 那一窗口复算，VOO / SPY / QQQ / IWM 四只的进攻线和防守线与日报 11/05 那份数据逐位一致。 判定口径是 VOO / QQQ / IWM；本页标的池里是 SPY，所以梯子上另给了 SPY 自己的同口径线 （VOO 距防守 −2.94% vs SPY −2.91%，两者基本重合）。它是描述性的，不预测方向。
